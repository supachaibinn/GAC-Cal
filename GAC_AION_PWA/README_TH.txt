GAC AION Installment Calculator — PWA

ไฟล์ในชุดนี้
- index.html: เว็บไซต์คำนวณค่างวด
- manifest.webmanifest: ชื่อแอป/ไอคอน/โหมด standalone
- service-worker.js: cache ไฟล์หลักให้เปิดซ้ำแบบออฟไลน์ได้
- icons/: ไอคอนแอป 192 และ 512 px

วิธีเผยแพร่ที่ง่ายที่สุด: Netlify Drop
1. แตกไฟล์ ZIP นี้ในคอมพิวเตอร์
2. เข้า https://app.netlify.com/drop
3. ลากโฟลเดอร์ GAC_AION_PWA ที่แตกแล้ว (หรือเลือกอัปโหลดโฟลเดอร์ที่มี index.html อยู่ระดับบนสุด) ไปวาง
4. รอ Netlify เผยแพร่ แล้วเปิด URL ที่ได้ด้วย https://...
5. ทดสอบลิงก์บนมือถือก่อนแชร์ให้ลูกค้า

ติดตั้งบน Android (Chrome)
1. เปิด URL ที่เผยแพร่แล้ว
2. แตะปุ่ม “ติดตั้งแอป” ที่แสดงบนเว็บไซต์ หรือเมนู Chrome > Install app / Add to Home screen
3. ยืนยันติดตั้ง ไอคอนจะอยู่บนหน้าจอหลัก

ติดตั้งบน iPhone/iPad (Safari)
1. เปิด URL ด้วย Safari (ไม่ใช่เบราว์เซอร์ในแอป LINE)
2. แตะ Share (สี่เหลี่ยมมีลูกศรขึ้น)
3. เลือก Add to Home Screen / เพิ่มไปยังหน้าจอโฮม แล้วแตะ Add / เพิ่ม

หมายเหตุ
- ต้องเผยแพร่ผ่าน HTTPS หรือรันผ่าน localhost จึงจะติดตั้ง PWA และใช้ Service Worker ได้
- Service Worker ช่วยให้เปิดหน้าเว็บที่เคยโหลดแล้วแบบออฟไลน์ได้ แต่การเปิดครั้งแรกต้องใช้อินเทอร์เน็ต
- ตัวเลขราคารถและส่วนลดในตัวอย่างเป็นราคาอ้างอิง ต้องตรวจสอบกับโชว์รูมก่อนเสนอให้ลูกค้า
- ชุดนี้ไม่ได้เชื่อมต่อระบบฐานข้อมูลหรือส่งข้อมูลลูกค้าไปที่ใด
